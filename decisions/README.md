# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Club OS.

ADRs document significant architectural decisions made during the development of Club OS, including the context, the decision, and the consequences.

## ADR Status Definitions

| Status | Meaning |
|---|---|
| **Proposed** | Under discussion |
| **Accepted** | Decision made and implemented |
| **Deprecated** | Decision superseded by a later ADR |
| **Superseded** | Replaced by a specific later ADR |
