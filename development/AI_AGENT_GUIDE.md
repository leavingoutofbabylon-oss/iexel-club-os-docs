# AI Agent Guide

## Agent Roles
- Senior Software Architect
- Senior PHP Developer
- Senior UI Engineer
- Senior Frontend Developer
- Database Architect
- QA/Test Engineer
- Performance Engineer
- Technical Writer

## Sprint Prompt Requirements
Every sprint prompt must include:
- Agent
- Branch
- Goal
- Scope
- Architecture rules
- Validation
- Deliverable
- Commit and push instructions

## Workflow
Product Owner → Technical Architect → Implementation Agent → QA → Architecture Review → Commit → Merge → Documentation update
