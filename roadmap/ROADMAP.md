# Product Roadmap

**Last verified:** 2026-07-24

---

## Overview

This roadmap describes the planned evolution of Club OS beyond the MVP release. It is a living document and will be updated as priorities change.

---

## Version 1.0 — MVP Release

**Target:** Current sprint

The MVP delivers the complete core platform. See [MVP_STATUS.md](MVP_STATUS.md) for the full module status.

**Key deliverables:**
- Complete member, team and season management
- Match Mode for live match operations
- Finance management (invoices, payments, billing schedules)
- Member Portal with five experience roles
- Communications (email)
- Player registrations
- Club Projects
- Executive Dashboard

---

## Version 1.1 — Post-MVP Hardening

**Target:** 1–2 sprints after 1.0

**Key deliverables:**
- Finance export (CSV/PDF)
- Weather integration for event pages
- `iexel_manage_teams` capability enforcement
- `iexel_manage_communications` capability enforcement
- Audit Log UI (`iexel_view_audit_log`)
- Legacy repository migration to `app/core/`
- Test coverage for P1 modules

See [VERSION_1_1.md](VERSION_1_1.md) for detailed planning.

---

## Version 2.0 — Platform Expansion

**Target:** 3–6 months after 1.0

**Key deliverables:**
- Rewards module
- Multi-club support
- Public-facing club website integration
- Mobile app (React Native)
- Payment gateway integration
- Advanced statistics and reporting

See [VERSION_2_0.md](VERSION_2_0.md) for detailed planning.

---

## Long-Term Vision

- Club OS as a SaaS platform for grassroots football clubs
- League and federation integration
- Player development tracking
- Volunteer management
- Sponsorship management
